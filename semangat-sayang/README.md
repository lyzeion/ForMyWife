# Semangat Sayang

Web penyemangat untuk pacar.

## Struktur
- index.html : isi halaman
- style.css  : tampilan dan warna
- script.js  : nama, hitung hari, galeri foto, pesan acak
- images/    : taruh foto di sini

## Cara membuka
1. Buka folder ini di VS Code (File > Open Folder).
2. Pasang ekstensi Live Server.
3. Klik kanan index.html > Open with Live Server.

## Memasang foto permanen
Taruh foto di folder images/ (misal images/foto1.jpg), lalu di index.html
ganti isi tiap kotak galeri atau ubah script.js agar memakai src="images/foto1.jpg".
